# 📊 Dashboard Power BI – QG Barbershop

Este projeto é um case fictício de análise anual de uma barbearia chamada **QG Barbershop**, com foco em identificar oportunidades de crescimento, aumento do ticket médio e estratégias de marketing baseadas em comportamento de consumo.

## 💡 Objetivo

Analisar os serviços e produtos mais vendidos, frequência de atendimento por cliente, ticket médio e receita total anual para entender o perfil dos clientes e gerar insights de expansão e fidelização.

---

## 📁 Arquivos

- `dashboard_qg_barbershop_analise_anual.pbix` – Arquivo Power BI com o dashboard finalizado.
- `atendimentos_qg_barbershop.csv` – Base fictícia com 250 clientes e atendimentos.
- `produtos_qg_barbershop.csv` – Base complementar com as vendas de produtos.
- `README.md` – Este documento explicativo.

---

## 📌 Principais Métricas

- Total de clientes atendidos
- Receita anual por cliente
- Ticket médio por atendimento
- Serviços mais vendidos
- Produtos mais vendidos
- Faixa etária dos clientes
- Frequência de visitas
